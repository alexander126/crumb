# Crumb 0.0.1-rc.2

`0.0.1-rc.2` finalizes the public package identities for the first native Crumb
release while preserving the SDK APIs validated in `0.0.1-rc.1`.

## Package identities

- Swift Package Manager products remain `CrumbCore` and `CrumbUI`.
- CocoaPods publishes `CrumbSDK`, `CrumbSDKCore`, and `CrumbSDKUI`; the installed
  Swift modules remain `CrumbCore` and `CrumbUI`.
- Maven publishes `com.crumbsdk:crumb-core` and
  `com.crumbsdk:crumb-ui`; Android source packages remain under `dev.crumb`.

## Verification

The exact candidate commit must pass `npm run release:check`, remote clean
consumer installation, `npm run release:prepare`, and `npm run release:verify`.
Staging dogfood follows [`docs/quality/t14-dogfood.md`](../quality/t14-dogfood.md).

## Release boundary

- The final `0.0.1` tag and public CocoaPods/Maven Central publication remain
  gated by staging dogfood and registry ownership verification.
- React Native, AI grouping, integrations, and the internal operations console
  remain outside `0.0.1`.
- Hosted API, dashboard, infrastructure, and operations remain private in the
  separate `crumb-cloud` repository.
