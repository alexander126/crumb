# Crumb 0.0.1-rc.1

`0.0.1-rc.1` is the first reproducible release candidate for the native Crumb
iOS and Android SDKs. It is intended for staging dogfood and integration review,
not production deployment.

## Included

- Native iOS and Android reporter lifecycle with button and foreground-shake
  invocation.
- On-device screenshot masking, bounded diagnostics and sanitized logs.
- Durable local queues with idempotent, connectivity-aware upload recovery.
- Swift Package Manager, CocoaPods, and staged Maven distribution shapes.
- Local-by-default dogfood hosts for the isolated Crumb staging project.
- Apache-2.0 licensing, privacy documentation, release manifest and SHA-256
  checksums.

## Verification

The exact candidate commit must pass `npm run release:check`, remote clean
consumer installation, `npm run release:prepare`, and `npm run release:verify`.
Staging dogfood follows [`docs/quality/t14-dogfood.md`](../quality/t14-dogfood.md).

## Known release boundary

- The final `0.0.1` tag and public registry publication are not part of this
  candidate.
- React Native, AI grouping, integrations, and the internal operations console
  are outside `0.0.1`.
- Hosted API, dashboard, infrastructure and operations remain private in the
  separate `crumb-cloud` repository.
- The public SDK repository starts from an audited SDK-only snapshot. Earlier
  internal history is retained privately because it predates the cloud/SDK
  repository boundary.
